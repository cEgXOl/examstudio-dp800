# Contribuir

Gracias por ayudar a mejorar ExamStudio. Puedes abrir una incidencia para describir un problema o una propuesta y enviar una pull request con tu cambio.

1. Crea un fork y una rama para tu cambio.
2. Conserva la fidelidad de las preguntas y respuestas del PDF, salvo que la PR explique y justifique una corrección.
3. Ejecuta `npm test`; para cambios en la función de Netlify, instala dependencias y ejecuta también `npm run build`.
4. Describe el problema, la solución y las pruebas realizadas en la pull request.

No incluyas contraseñas, claves, datos personales ni contenido privado en el código, capturas, pruebas o mensajes. Usa valores de prueba y variables de entorno locales. Las pruebas y los despliegues de vista previa deben usar su propio almacenamiento, no el de producción.
